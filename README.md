# ConsoleMode - Vanilla

**ConsoleMode - Vanilla** is a custom controller/gamepad experience addon built for World of Warcraft 1.12 (Vanilla / Turtle WoW), specifically tailored for handheld gaming devices like the Steam Deck.

---

## 🎯 Objective

The main goal of this addon is to bring a modern controller experience inspired by the renowned **ConsolePort** addon (available for Retail World of Warcraft) into the 1.12 Vanilla / Turtle WoW client, focusing on performance, modularity, and seamless interface navigation.

## 🎮 Features (In Development)

- **Cursor Navigation**: Seamless UI navigation with gamepad/D-Pad and keyboard across game windows, menus, dialogs, and bags.
- **Auto-Snap**: Instant focus on dialog options, quest accept/complete buttons, and NPC interactions.
- **Controller-Friendly UI**: Optimized for handheld devices (Steam Deck, ROG Ally, etc.).
